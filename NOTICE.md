# Attribution

This repository contains custom packaging, an optional Grok CLI relay, and agent instruction templates for [OpenBot](https://github.com/nightly-labs/openbot).

OpenBot is developed by its upstream authors and is distributed under PolyForm Noncommercial 1.0.0. The same license is included here. This is an independent customization project, not an official OpenBot release.

The macOS packager includes a locally supplied official OpenBot application without modifying its files or signature. The upstream application, its third-party notices, and its licenses remain inside that application. Application binaries are not included in this Git repository.

The original personal macOS package used OpenBot 0.65.0. The published build scripts remove personal paths and use local settings instead. Windows customization packaging has not been implemented or tested.
